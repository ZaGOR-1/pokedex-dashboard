# Pokédex Analytics

Навчальний проєкт із дисципліни **«Компонентно-орієнтоване програмування»**.

**Варіант №6: Pokédex**

Проєкт розробляється протягом семестру на основі лабораторних робіт. Кожна наступна лабораторна доповнює функціональність попередньої.

Мета проєкту полягає у вивченні React, створенні компонентів, роботі зі станом, обробці подій та правильній організації коду.

## Лабораторна робота №1

**Тема:** Simple Dashboard Widgets

У першій лабораторній роботі створено початкову версію дашборду Pokédex. Для демонстрації використовуються 12 покемонів, дані яких зберігаються локально. Підключення до PokeAPI буде реалізовано в наступних лабораторних.

### Реалізовані можливості

- **KPI-картки:** відображення кількості покемонів, унікальних типів та покемонів із двома типами.
- **Лічильник:** збільшення, зменшення та скидання кількості місць у команді. Діапазон від 0 до 6.
- **Перемикач теми:** можливість перемикання між світлою та темною темою.
- **Фільтрація покемонів:** вибір типу, відображення відповідних покемонів та скидання фільтра.
- **Адаптивний дизайн:** інтерфейс підлаштовується під різні розміри екранів.

Для реалізації використано React-компоненти, `props`, `useState`, обробники подій та умовний рендеринг.

## Встановлення та запуск

Для запуску потрібні Node.js (рекомендовано версію 24.15 або новішу) та npm.

**1. Клонування репозиторію**

```bash
git clone https://github.com/ZaGOR-1/pokedex-dashboard.git
cd pokedex-dashboard
```

**2. Встановлення залежностей**

```bash
npm ci
```

**3. Запуск застосунку**

```bash
npm run dev
```

Після запуску потрібно відкрити адресу, яку покаже Vite в терміналі. Зазвичай це `http://localhost:5173`.

**4. Збірка проєкту**

```bash
npm run build
npm run preview
```

```text
src/
├── app/

├── components/
│   ├── KpiCard.tsx

│   └── pokemon/

```

Кожен віджет знаходиться в окремому компоненті. Дані передаються через `props`, а локальний стан зберігається за допомогою `useState`.

Демонстраційні дані винесено в окремий файл. Для фільтрації покемонів і підрахунку показників використовуються окремі функції, які не залежать від компонентів інтерфейсу.

## Тестування

Для перевірки роботи компонентів і функцій написано тести. Вони охоплюють роботу лічильника, перемикання теми, фільтрацію списку та підрахунок показників.

Команди для перевірки:

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```
